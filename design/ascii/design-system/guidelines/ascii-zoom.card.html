The rule: zooming the graph must never scale the characters. The cell stays 10.5px at every zoom level; what grows is the number of cells. A closer view therefore carries more edge detail and more named notes, at the same crisp type size — and, because nothing is CSS-scaled, an embedded graph can't drag the host page's zoom with it.
